# Toast

Confirms the copy after the app has gone back to the payment app. Floats over it for 2.5 s near the bottom, above the keyboard area.

- `signal` fill, `on-signal` text, 72px tall, `label`-size words, check icon. Comes with two short vibrations.
- Says only what happened. The next step (tap the number above the keyboard) is taught once on first use, not every time.
