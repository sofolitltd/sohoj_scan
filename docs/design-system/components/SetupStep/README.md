# SetupStep

One permission or phone setting per row on the setup screen. The row says what it is, why in five words, and either a "চালু করুন" button or a lime "হয়েছে".

- Only the next unfinished step has a button and a `line-strong` border; later ones wait, muted.
- The button opens the exact Android settings screen (per brand for Xiaomi, Oppo, Vivo, Realme, Infinix autostart).
- When the person comes back from settings, re-check and tick automatically with the locked sound.
