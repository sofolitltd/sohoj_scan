# NumberCard

Used when the paper or screen holds two or more valid numbers. One card per number, the whole card is the tap target.

- Number in `card` style (32px, one line), operator chip under it, a small chevron at the right.
- `surface` fill, 2px `line-strong` border, `radius-lg`, padding `space-6`, at least 112px tall, `space-4` apart.
- Order: the number nearest the centre of the scan box first.
- Tapping a card opens the normal result screen for that number (it is still read aloud before copy).
