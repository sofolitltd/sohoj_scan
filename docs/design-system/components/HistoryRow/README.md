# HistoryRow

The last 10 numbers, newest first, for when a customer comes back or a paste failed.

- Number in `row` style, time and operator in `caption`/`ink-muted`, a 64px copy button on the right.
- Rows are 88px tall at least; a divider `line` between them.
- Items older than 24 hours disappear on their own. One "সব মুছুন" secondary button at the bottom.
