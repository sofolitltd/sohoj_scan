# Logos

- `sohoj-mark.svg` — the app mark and the floating bubble face: a dark disc, a lime ring, four scan corners and the scan line. Colours are fixed (`bubble` + `signal`); it is the same in every theme so it reads over any app. Use it as the launcher icon foreground on a `#0B0C0A` background. No wordmark: the name is set in Atkinson Hyperlegible Next Bold.
