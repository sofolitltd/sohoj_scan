# Icons

24px grid, 2px round stroke, drawn in ink `#0E0F0C`. In the app recolor them (Flutter: `SvgPicture` with `ColorFilter`, or redraw as an icon font). Shown at `size-icon` (32px) in buttons, 24px only in chips. Every icon sits next to a word; none stands alone except the torch and close buttons, which carry a TalkBack label.

- `scan.svg` — scanner, bubble, tile
- `copy.svg` — the copy action
- `torch.svg` — flashlight toggle
- `speaker.svg` — read the number again
- `history.svg` — history list
- `check.svg` — locked, copied, setup step done
- `rescan.svg` — scan again
- `close.svg` — close scanner, dismiss
- `alert.svg` — error, missing permission
- `settings.svg` — settings
